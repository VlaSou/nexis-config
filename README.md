# @vlasou/nexis-config

Shared configuration presets for Vite, TypeScript, PostCSS, Vitest, Biome and Prettier.

This repository is the **PUBLIC mirror** of the reviewed `nexis-agent/nexis-config` project. It is not a Production mirror or a deployed application.

Sanitized source will be mirrored into `dev` using a dedicated GitHub App. A reviewed `dev → main` pull request authorizes publication of `@vlasou/nexis-config` to GitHub Packages (`https://npm.pkg.github.com`), not npmjs.com.

> Initial bootstrap commit. No private source files or private Git history are included.
